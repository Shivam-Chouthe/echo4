# Echo

> Save Now. Live Later. Your forgotten intentions, remembered.

Echo is a personal memory assistant that captures content across platforms, extracts core user intent using AI, and resurfaces it at the right time and place.

## Architecture
- `/android` — Native Android client (Kotlin, Jetpack Compose, Room)
- `/backend` — API & AI processing pipeline (FastAPI, Python)
- `/docs` — Product specifications, architecture decisions, and roadmap
